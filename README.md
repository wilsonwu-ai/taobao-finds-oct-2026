# Taobao Finds · October 2026

A swipeable, shareable list of the best things to buy on Taobao right now, shortlisted from 2025-2026 social buzz and kept only when real creator posts (YouTube, TikTok and Douyin) recommend them.

Live: https://wilsonwu-ai.github.io/taobao-finds-oct-2026/

- **Swipe** right to save, left to skip. Saved items live in "My list", which you can share.
- **Every item** links at least one real creator post.
- **Taobao check:** each item is being checked on Taobao for sales and buyer reviews before the Oct 20 sale (8pm Beijing time). Items marked "Taobao sales check pending" have not been checked yet.

Static site: `index.html`, `styles.css`, `app.js`, data in `items.json`. No build step, no trackers, no affiliate links. Not affiliated with Taobao.
